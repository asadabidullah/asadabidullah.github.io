Mods We Use

Everything you need to know about how our server runs.

Wait, no mods?

That's right! We currently don't use any client-side mods. Instead, we run the server on Paper and use powerful server-side plugins.

Pure Vanilla Feel

You can join with a standard, unmodded Minecraft client. No extra downloads required.

Better Performance

Paper is highly optimized, meaning less lag and faster tick rates for everyone playing.

Server-Side Magic

All the quality-of-life features, claiming, and protections happen behind the scenes.

Just launch standard Minecraft Java Edition, enter the server IP, and you're good to go. If we ever add modpacks in the future, you'll find the installation guides right here.
