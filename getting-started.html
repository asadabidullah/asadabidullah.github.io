Getting Started

How to join the server for the first time and get set up.

Already own Minecraft?

If you have bought Minecraft, you can skip the first 3 steps and jump straight to Step 4.

1

Download XMCL Launcher

Download and install the XMCL launcher to manage your game instances.

2

Make an Offline Account

Create an offline account within the XMCL launcher to bypass the official login.

3

Setup Agnes AI API Key

Go to your settings, generate an Agnes AI API key, and paste it into the XMCL AI agent section.

4

Create a Vanilla Instance

Make an instance of the latest vanilla release of Minecraft.

5

Launch & Join

Launch the game, put in the IP found on the main page, join, and enjoy!

Uptime Notice

Please note that the server is not online 24/7. Check the Discord for status updates if you can't connect.
